# 🚀 Engineering Projects

## ⚡ Variable Filter Design for Grid-Connected Inverter Systems

**Focus:** Power Electronics · MATLAB · System Design · Optimisation

Designed a **variable LCL filter methodology** for a 5 kW grid-connected inverter system.

The project investigated how inverter-side and grid-side inductance could be dynamically selected to accommodate different operating conditions and optimise competing engineering requirements.

### Key objectives

* 📉 Reduce total harmonic distortion (**THD**)
* 📦 Minimise inductor core volume
* ⚡ Reduce power losses
* 🌡️ Account for temperature variations
* 🔌 Maintain compliance with **IEEE 519** current-ripple requirements

**Result:** Developed a filter design approach capable of achieving **THD below 5%** across the investigated design scenarios.
